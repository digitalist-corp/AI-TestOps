## 2. 11/17 dev에 들어간 기능 (시연 순서대로)

**로그인 · 계정 (개편 ②, #103 #105)**
- 회원가입: 누구나 가입, 가입 즉시 팀원. 가입은 IP당 분당 5회 제한
- "게스트로 시작": 관리자가 아닌 별도 팀원 계정으로 입장, 시연 프로젝트(example.com)만 보임
- 역할: 관리자(전역) · PM · 팀원(프로젝트별). 같은 사람이 A에선 PM, B에선 팀원 가능

**프로젝트 (개편 ① ② ⑤, #94 #95 #104 #117 #120)**
- 등록은 관리자만, 등록할 때 PM 지정. 아이디는 서버가 `P0001`처럼 자동 부여
- 카드: 프로젝트 이름 크게, 상태(계획 · 실행 · 종료) · 기간 · 진척률, 실행 중이면 진척 막대
- 환경(개발 · 테스트 · 운영), 사이트 주소 열기, 담당자 검색, 부가설명 제거
- 전체 실행 전 확인 팝업("'쇼핑몰' 프로젝트를 실행할까요? 실행할 항목 N건")
- 수정 · 삭제는 프로젝트 설정 화면 안으로, 팀원 탭에서 PM은 팀원 추가 · 제외, 관리자는 PM 지정

**계획 (A트랙 + 개편 ⑤, #76 ~ #79 #119)**
- 엑셀형 계획 표: 순서 끌어 옮기기, 사용 여부, 담당자 · 기한 · 우선순위, 최신 결과
- 담당자는 프로젝트 멤버 중에서 고름 (예전 글자 담당자는 "(계정 없음) 이름"으로 남김)
- 스위트로 거르기 + 성공 · 실패 · 미수행 · 미사용 건수
- 화면 지도: 화면 썸네일, 연결이 많을수록 진하게, 최다 연결 화면에 "핵심" 표시

**대시보드 · 첫 화면 (#73 #107)**
- 팀원: 내 프로젝트 · 집계 · 실패 재실행 · 나에게 배정된 항목
- PM: 내 프로젝트 진척률 · 담당자별 진행
- 관리자: 전체 프로젝트 · 사용자 · 러너 현황
- 모든 역할: 최근 공지 3개

**공지 · 기록 (개편 ④ ⑤, #116 #118)**
- 공지사항: 관리자만 작성 · 고정 · 게시 기간, 새 공지는 모든 사용자 알림 종에 표시
- 사람이 고치는 테이블에 수정자 · 수정일 자동 기록, 프로젝트 정보 · 계획 표에 "최근 수정" 표시

**AI 흐름 (#69 #70 #72)**
- 실패한 실행에서 수정 제안 카드 자동 생성 → 사람이 승인해야만 반영 (승인 없는 반영 경로 전부 차단)
- AI 작업 큐 화면과 실시간 진행 통로

**보안 (#105 리뷰 반영)**
- 프로젝트 하위 API 전체에 멤버 · 역할 검사 한 곳 (`ProjectAccessInterceptor`), 쓰기는 허용 목록 방식
- `/api/users` 관리자 전용으로 막음, 주소에 `;`가 들어간 요청 거절(권한 우회 차단)
- AI 분석 · 사이트맵 · 스트림 같은 공용 경로도 멤버 검사
