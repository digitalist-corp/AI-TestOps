## 1. E-02 MCP 스모크 (11/19 정오 마감, 중간 보고 2번)

- 스킬: brainstorming(범위는 E-01 결정이 정함, 허용 도구 목록만 내가 정해 기록) → writing-plans → executing-plans(TDD) → requesting-code-review → verification
- Spring `/mcp`: MCP Java SDK 코어(Boot 3.3 · Jackson 2 호환 버전). 막히면 `initialize` · `tools/list` · `tools/call` 만 받는 무상태 JSON-RPC 컨트롤러
- 인증: `Authorization: Bearer <ai_jobs.callback_token>` (작업 전용 토큰, 30분)
- 공개 도구는 허용 목록(조회 도구만, 시작은 `list_executions`). 파일 쓰는 도구 없음. `ApprovalGateInventoryTest` 유지
- ai-service: `langchain-mcp-adapters` `MultiServerMCPClient`(transport http)로 `list_executions` 호출 → 결과 받기 = 완료
- 실패 판정 · 3안(LangGraph4j) 전환 여부는 근거와 함께 정오 보고
